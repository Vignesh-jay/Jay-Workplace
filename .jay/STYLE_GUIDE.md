# JAY Coding Standards

## Technology

- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript
- localStorage

## Rules

- Use const whenever possible.
- Use let only when necessary.
- Use single quotes.
- Use semicolons.
- Keep functions short.
- Never duplicate code.
- Reuse helper functions.
- Keep UI and storage separate.
- Match the existing design language.

## Naming

Pages

employees.js

assets.js

reports.js

Services

employee.service.js

asset.service.js

department.service.js

Variables

camelCase

Constants

UPPER_CASE

Functions

verbNoun()

Examples

loadEmployees()

saveAssets()

renderDashboard()
